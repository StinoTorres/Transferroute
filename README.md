# Transferroute

Elke dag een Eredivisie-speler raden aan zijn transferroute.

Speel: https://stinotorres.github.io/Transferroute/

## Als app installeren
- **iPhone (Safari):** Delen → *Zet op beginscherm*
- **Android (Chrome):** menu ⋮ → *App installeren* (of de melding onderin)

De app opent schermvullend en werkt ook zonder internet.
